画像変換ツール

使い方ガイド  |  HEIC・JPEG・PNG・WebP などの画像形式を変換するツールです

① 起動方法

  1. 「画像変換ツール.exe」をダブルクリックします アプリが起動し、変換ウィンドウが表示されます。
  2. 「WindowsによってPCが保護されました」という画面が出た場合 「詳細情報」→「実行」の順にクリックしてください。
    このツールは安全ですが、配布元が未登録のため Windows が警告を表示することがあります。

② 基本的な使い方

  1. 変換したいファイルを追加する 「ファイル追加」ボタンで1枚ずつ選ぶか、「フォルダ追加」でフォルダ内の画像をまとめて追加できます。
  2. 変換形式を選ぶ ドロップダウンから出力したい形式（JPEG・PNG・WebP など）を選択します。
  3. 出力先フォルダを指定する（任意） 「選択」ボタンで保存先フォルダを指定できます。
    空欄のままにすると、元のファイルと同じフォルダに保存されます。
  4. 品質を調整する（任意） JPEG・WebP 形式のときのみ有効です。数値が高いほど高画質・大容量になります。
    デフォルトの 85% が画質とファイルサイズのバランスが良い設定です。
  5. 「変換開始」ボタンをクリック 進捗バーが進み、各ファイルの状態が「完了」または「失敗」と表示されます。
出力先を指定した場合指定フォルダ / photo01.jpg
出力先を空欄にした場合元ファイルと同じフォルダ / photo01.jpg

③ 対応している形式

以下の形式を入力・出力に使用できます。同じ形式同士の変換（例：JPEG → JPEG）も可能です。

形式 透過（背景なし） 品質設定 主な用途
JPEG なし あり 写真・一般的な画像
PNG あり — スクリーンショット・ロゴ
WebP あり あり Web向け・高圧縮
BMP なし — 無圧縮・高互換性
TIFF あり — 印刷・業務用途
HEIC / HEIF — — iPhone の写真形式（入力のみ）

④ 注意事項

  • !
    元のファイルは削除・上書きされません 変換後も元の画像はそのまま残ります。安心して変換してください。
  • !
    PNG → JPEG に変換すると透過部分が白くなります JPEG は透過に対応していないため、透明な部分は自動的に白色の背景に変換されます。
  • !
    出力先フォルダに同名ファイルがある場合は上書きされます 例：変換先に「photo01.jpg」が既にある場合、新しいファイルで上書きされます。
    重要なファイルは事前にバックアップを取っておくことをお勧めします。
  • i
    JPEG の品質は 85% がおすすめです 100% は見た目の差がほぼなくファイルサイズだけ大きくなります。
    SNS 投稿用なら 80〜85%、印刷用なら 90〜95% が目安です。
  • i
    フォルダ追加はサブフォルダも含めて検索します フォルダ内に複数階層がある場合も、すべての画像ファイルを自動で見つけます。
  • i
    変換中はアプリを閉じないでください 進捗バーが完了するまでウィンドウを開いたままにしておいてください。
