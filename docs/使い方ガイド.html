🔄 拡張子変換ツール

使い方ガイド  |  画像・動画・文書のファイル形式をまとめて変換できるツールです

① 起動方法

  1. 「拡張子変換ツール.exe」をダブルクリックします アプリが起動し、「画像変換」「動画変換」「文書変換」の3つのタブがあるウィンドウが表示されます。
  2. 「WindowsによってPCが保護されました」という画面が出た場合 「詳細情報」→「実行」の順にクリックしてください。
    このツールは安全ですが、配布元が未登録のため Windows が警告を表示することがあります。

🖼️ 画像変換タブ

  1. 変換したいファイルを追加する 「ファイル追加」ボタンで1枚ずつ選ぶか、「フォルダ追加」でフォルダ内（サブフォルダ含む）の画像をまとめて追加できます。
  2. 変換形式を選ぶ ドロップダウンから出力したい形式を選択します。
  3. 品質を調整する（任意） JPEG・WebP・AVIF 形式のときのみ有効です。デフォルトの 85% がバランスの良い設定です。
  4. 出力先フォルダを指定する（任意） 空欄のままにすると、元のファイルと同じフォルダに保存されます。
  5. 「✨ 変換開始」ボタンをクリック 進捗バーが進み、各ファイルの状態が「完了」または「失敗」と表示されます。

対応形式

形式透過品質設定主な用途
JPEGなしあり写真向け・高互換
PNGあり—透過対応・可逆圧縮
WebPありありWeb向け・高圧縮
AVIFありあり次世代・超高圧縮
BMPなし—無圧縮・高互換
TIFFあり—印刷・業務向け
HEIC / HEIF——iPhoneの写真形式（入力のみ）

🎬 動画変換タブ

  1. 動画ファイルを選択する 「動画ファイルを選択」ボタンから1本選びます（対応：MP4 / MOV / AVI / MKV / WebM / M4V）。
  2. 変換後の形式を選ぶ MP4・WebM・GIF・MP3（音声抽出）から選択できます。GIFはフレームレート・横幅も調整可能です。
  3. 「✨ 変換開始」ボタンをクリック 変換ログが画面に表示され、完了すると保存先が案内されます。
⚠️ 動画変換には FFmpeg のインストールが必要です。インストールされていない場合、このタブは使用できません。

📄 文書変換タブ

  1. 文書ファイルを選択する 対応形式：TXT / DOCX（Word） / PDF / XLSX（Excel） / PPTX（PowerPoint）
  2. 変換後の形式を選ぶ 選んだファイルの種類によって、選択できる出力形式が自動的に変わります。
  3. 解像度を選ぶ（画像化・PPTX変換のみ） 96dpi（画面用）・150dpi（標準）・300dpi（印刷用）から選べます。
  4. 「✨ 変換開始」ボタンをクリック

組み合わせ表

入力変換できる形式
TXT→ PDF・DOCX・JPEG・PNG・WebP
DOCX（Word）→ PDF・TXT・JPEG・PNG・WebP
PDF→ TXT・DOCX・PPTX・JPEG・PNG・WebP
XLSX（Excel）→ PDF・CSV・JPEG・PNG・WebP
PPTX（PowerPoint）→ PDF・TXT・DOCX・JPEG・PNG・WebP
📷 PDF → DOCX（Word）変換について：
文字が選択できる通常のPDFは、レイアウトを保ったままWordに変換されます。
スキャンした紙の書類のような「画像PDF」（文字が選択できないタイプ）は、自動的にOCR（文字認識）が行われ、 横書き・縦書きどちらのレイアウトでも認識してテキストとしてWordに書き込まれます。
※ OCR機能を使うには、別途 Tesseract-OCR（日本語データ含む）のインストールが必要です。未インストールの場合はエラーメッセージで案内されます。
⚠️ PDF以外の形式からPDF・画像への変換、および PPTX 変換には LibreOffice のインストールが必要です。

⚠️ 共通の注意事項

  • !
    元のファイルは削除・上書きされません 変換後も元のファイルはそのまま残ります。安心して変換してください。
  • !
    出力先フォルダに同名ファイルがある場合は上書きされます 重要なファイルは事前にバックアップを取っておくことをお勧めします。
  • !
    PNG → JPEG に変換すると透過部分が白くなります JPEGは透過に対応していないため、透明な部分は自動的に白色の背景に変換されます。
  • i
    複数ページ／複数ファイルの出力はZIPでまとめられます 画像化などで出力が複数になる場合、自動的にZIPファイルとしてまとめて保存されます。
  • i
    変換中はアプリを閉じないでください 進捗バーやログが完了するまでウィンドウを開いたままにしておいてください。
